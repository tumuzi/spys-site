# SPYS website

SPYS の公開案内サイト。GitHub Pages 用の静的 HTML/CSS です。ゲーム本体の非公開リポジトリとは分けて管理します。

## ページ

- `index.html`：ゲームの案内
- `assets/games/`：ミニゲーム紹介の画面キャプチャ（ゲーム本体リポジトリの `docs/mockups/screens/` から選定）
- `privacy.html`：プライバシーポリシー
- `support.html`：問い合わせ・報告・削除案内
- `licenses.html`：アプリで使う外部素材の帰属とライセンス

## 公開状況

- iOS 1.1 は App Store で審査中。Android はテスト配布中。公開状況が変わったらトップページも更新する。
- アプリの保存・削除の仕組みを変えたら、プライバシーポリシーも合わせる。
